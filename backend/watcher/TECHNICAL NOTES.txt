TECHNICAL NOTES - iEvaluate Scan Watcher (for IT staff)
=======================================================
End users: read "HOW TO INSTALL.txt" instead.

WHAT IT IS
  folder_watcher.py (Python 3.10+, deps in requirements.txt: requests, Pillow,
  PyMuPDF). Watches one scan folder (recursively), converts every finished page
  (.jpg .jpeg .png .tif .tiff .pdf; multi-page TIFF/PDF are split) to a grayscale
  ~200 dpi JPEG and POSTs it to <api_base>/scans/ingest with header
  X-Station-Key while a batch is open for the station (no batch open: nothing
  is sent, files wait). Sent files are moved to <folder>\processed\<date>\,
  pages scanned before the batch started to <folder>\skipped\before-batch\,
  other unusable ones to <folder>\skipped\.
  2.4.1+: a page marking still couldn't save after several tries, but that
  the server kept a copy of for its review page ("Couldn't be saved": Try
  again / enter the answers by hand), counts as sent and goes to processed\
  (no rescan needed). Older watchers set such files aside in skipped\.
  2.4.3+: a network folder (\\server\share\... or //server/share/...) sent
  from the website is refused (old folder kept, website shows "folder isn't
  allowed"); set one by hand in watcher_config.json if really needed. A
  "server busy" reply (HTTP 503 + Retry-After, too many pages at once) is
  retried after the time the server asks for.
  2.4.4+: heartbeat every 15 s (was 30 s), plus a small keep-alive while a
  slow page upload blocks the main loop, so the website's light can turn red
  ~40 s after the watcher stops (older watchers: 90 s). UNINSTALL (and Ctrl+C
  in the watcher window) tells the website at once (POST /scans/offline).
  2.5.0+: NO auto-start at log-on. INSTALL creates "Start Scan Watcher" and
  "Stop Scan Watcher" shortcuts on the desktop and in the Start Menu (folder
  "iEvaluate Scan Watcher"); users start the watcher by hand before scanning.
  INSTALL still starts it once at the end. STOP.bat stops the watcher and
  tells the website offline at once. A single-instance lock stops a second
  copy: it exits with code 7. Re-running INSTALL on a 2.4.x laptop removes the
  old auto-start. IT can opt in to auto-start with install_task.bat.
  The website shows a note for stations still reporting a version below 2.5.0.

THE PACKAGE (ScanWatcher-<station>.zip, top folder ScanWatcher\)
  INSTALL.bat          one-click installer (see below)
  UNINSTALL.bat        stop + remove shortcuts/auto-start (scans untouched)
  CHECK.bat            read-only status report in plain words
  watcher_config.json  per-station settings, generated by the website. Contains
                       the station SECRET key. Each "Download installer" makes a
                       NEW key and the previous key stops working at once.
  folder_watcher.py, requirements.txt, setup_helper.py (installer/CHECK helper),
  start_watcher.bat (run loop), find_python.bat, watcher_process.bat,
  install_task.bat / uninstall_task.bat (optional auto-start on/off, IT only),
  the two .txt guides.

  watcher_config.json:
    { "api_base": "https://<backend>", "station_key": "<secret>", "folder": "C:/Scans" }
  "folder" is optional (default C:/Scans). Use forward slashes (backslashes are
  tolerated). Optional: "processed_dir", "skipped_dir", "poll_seconds".

WHAT INSTALL.bat DOES (safe to re-run; re-running = clean reinstall)
  1. Refuses to run from inside the zip / %TEMP% or with files missing; needs
     watcher_config.json next to it.
  2. Finds Python 3.10+ (py -3, %LOCALAPPDATA%\Programs\Python\Python3*,
     %ProgramFiles%\Python3*, python, python3). If none:
       winget install -e --id Python.Python.3.12 --scope user
     and, if winget is missing/fails, opens python.org and stops.
  3. Stops every running watcher (any folder, incl. old installs and the old
     "iEvaluate Scan Watcher" scheduled task), then
       <python> -m pip install -q -r requirements.txt      (3 tries)
  4. Copies the program + watcher_config.json to  %LOCALAPPDATA%\ScanWatcher\
     (the extracted download can be deleted afterwards), removes the
     downloaded-from-internet mark (Unblock-File), creates the scan folder.
  5. Shortcuts (2.5.0+): "Start Scan Watcher" and "Stop Scan Watcher" on the
     desktop and in the Start Menu folder "iEvaluate Scan Watcher". No
     auto-start is created. Any old auto-start is removed: the Startup-folder
     shortcut "iEvaluate Scan Watcher.lnk" and the old "iEvaluate Scan
     Watcher" scheduled task (asks for UAC only if the old task needs it).
     No admin rights needed otherwise.
  6. Starts start_watcher.bat minimized, checks the server answers and the
     process is running.
  start_watcher.bat restarts the watcher 10 s after any exit and refuses to
  start a second copy of the same install.

FOLDER HANDLING
  - Default C:\Scans. Created automatically (by INSTALL, and by the watcher 2.4.2 only
    at start-up and only for C:\Scans when its parent exists). A folder set on the
    website is never created by the watcher: it must already exist, otherwise
    the website shows "Folder not found" (so a typo can't quietly make a folder).
  - Website folders must be full paths. Shortcuts (%NAME%, ~) are refused by the
    website and by the watcher (reported as "isn't allowed"). Only a hand-edited
    watcher_config.json (IT only) may still use %VARS%.
  - Website folders must be on the laptop itself: network shares
    (\\server\share\..., //server/share/...) are refused by the website, never
    sent in a heartbeat, and ignored by watcher 2.4.3+ if they arrive anyway.
    Only a hand-edited watcher_config.json may point at a folder inside a share.
  - Folder set on the website: every heartbeat (15 s; 10 s while files wait)
    returns the station's folder. The watcher hot-switches within ~15 s, no
    restart, and saves the new folder into watcher_config.json.
  - Unsafe folders are refused (drive roots, the user folder, root of
    Desktop/Documents/Downloads/OneDrive, Windows, Program Files). If the local
    config folder is unsafe the watcher does NOT watch, reports "folder isn't
    allowed" to the website, and waits until a safe folder is set there. An
    unsafe folder pushed from the website is ignored (old folder kept).
  - Missing folder (e.g. USB/network drive absent): retried; website shows
    "Folder not found". No permission: "Can't open the folder".

STATUS LIGHT ON THE WEBSITE (from heartbeats)
  green "Online - watching <folder>" | red "Offline" (no heartbeat for 40 s,
  WATCHER_ONLINE_SECONDS on the server; 90 s for watchers before 2.4.4: laptop
  off, no internet, watcher not started (2.5.0+ does not auto-start), key
  rejected; at once after UNINSTALL or STOP) | amber
  "Folder not found" / "That folder isn't allowed" / "Can't open the folder".

DE-DUPLICATION / RE-SEND RULE
  A page = (batch id, SHA-256 of the converted JPEG), stored in
  watcher_state.db. A restart never re-sends a page to the SAME batch; the server
  is idempotent too. A file counts as scanned at the LATEST of: its modified
  time, its creation time (a copied file gets a new one), and - for files that
  appear while the watcher is running - the moment the watcher first saw it
  (so copied or moved-in files are fine). Files already in the folder when the
  watcher starts use only modified/creation time. The same file dropped in
  while a NEW batch is open is sent to that batch only if that time is after
  the batch started. Older files go to skipped\before-batch\ and the website
  shows how many are waiting there: "add to batch" puts them back (they are
  sent to the open batch), "discard" moves them to
  skipped\discarded\<date>\ (never deleted). Done on the next heartbeat.
  No open batch: files wait in the folder and nothing is sent.
  Marking switched off on the server (no scoring pipeline): pages wait and are
  retried after 30 s, 1, 2, 4, then every 5 minutes.
  Scanner auto-rotate may stay on or off; the server fixes orientation.

FILES AND LOGS (all in %LOCALAPPDATA%\ScanWatcher\)
  watcher.log (+ .1-.5, 2 MB each)   activity log - first place to look
  watcher_state.db                   pages already sent, per batch
  watcher_config.json                settings + secret key (do not share)

COMMON LOG MESSAGES
  "No open batch on this station"     normal; scans wait for a batch
  "Station key rejected"              a newer installer was downloaded for this
                                      station; install that one (or re-download)
  "heartbeat failed" / "network error" no connection to <api_base>; auto-retry
  "Scan folder not found"             folder/drive missing; auto-retry
  "too big to watch"                  unsafe folder; set a safe one on the website
  "scanned before the current batch started - set aside in skipped/before-batch/"
                                      see above; add them to the batch on the website
  "marking is switched off"           server has no scoring pipeline; pages wait
  "can't reach the database"          server-side connection problem; auto-retry
  "Config problem"                    watcher_config.json broken; re-download

UNINSTALL
  UNINSTALL.bat: stops the watcher, removes the Start/Stop shortcuts, any old
  Start-up shortcut and any scheduled task. Leaves the scan folder, scans and %LOCALAPPDATA%\ScanWatcher
  (delete that folder by hand to remove the key/logs). Python stays installed
  (remove it in Settings - Apps if unwanted).

MANUAL INSTALL (fallback, e.g. no winget / locked-down PC)
  1. Install Python 3.10+ from python.org (tick "Add python.exe to PATH").
  2. Put the package files + watcher_config.json in a permanent folder.
  3. py -3 -m pip install -r requirements.txt
  4. Test: py -3 folder_watcher.py     (Ctrl+C to stop; --config <file> optional)
  5. Optional auto-start at log-on (IT only): install_task.bat  (remove: uninstall_task.bat)

MOVING / REPLACING A LAPTOP
  Download the installer for the station on the website and run INSTALL on the
  new laptop. This creates a new key; the old laptop goes "Offline" (key
  rejected). Run UNINSTALL on the old laptop if it is still in use.
